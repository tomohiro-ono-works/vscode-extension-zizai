## Goal（ゴール）

VS Codeの開発用拡張起動・終了時に出るエラーと警告の発生元・影響を切り分け、必要な対応と再確認方法を判断できる。

## Scope（スコープ）

- 対象：DisposableStore／doCreateOutputChannelエラー、DEP0169（url.parse）、DEP0040（punycode）、終了時の「プロセスが見つかりません」と文字化け。別々の事象として調べる。
- 正本・更新経路：本ファイルが進行・判断の記録、既存の調査記録が根拠、tests/manual/が再現手順、.vscode/が診断起動設定。既存資料へリンクし、ログや手順を重複管理しない。dist/は生成物で直接変更しない。
- 対象外：Zizai本体・コネクタ・独自実行基盤の実装、他Taskの代行、VS Code本体や他拡張の直接patch、ユーザーのグローバル設定の無断変更。
- 今回は起票と既存成果の引き継ぎのみ。新たな実機操作・修正・環境変更は行わない。

## Constraints（制約）

- VS Code 1.142.0／Windowsでの既存報告を基準にし、他版の成立を推測しない。Kiroは今回の対象外。
- セル選択UIの実機成立と起動エラーの解消は別に判定する。TASK-001-01の完了条件へ戻さない。
- 新試作0.0.3はOutputChannelを作らない。他拡張やVS Code内部を含む呼出元は未特定で、Copilot等をログの近接だけで原因と断定しない。
- クラウドでの文字コード再現やソース照合を、Windowsでのエラー解消確認と扱わない。

- [ ] 自前コード／依存／IDE・他拡張の責任範囲と、修正・上流報告・回避策等の具体的な対応を整理する。
