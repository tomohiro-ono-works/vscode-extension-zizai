# Notebook UIの呼称と選択メニューの整理

日付：2026-10-19。利用者との会話で合意し、Gitへの反映・pushを依頼された内容を記録する。

## 共通の呼び方

| 呼称 | 指すもの |
| --- | --- |
| HTMLフォーム | HTMLで描画する入力欄・プルダウン等のUI |
| セルツールバー | Notebookのセルに付く操作ボタンと、そこから開くメニュー |

どちらもZizai拡張が提供するUIの一部であり、別の拡張機能を意味しない。

## 今回話している選択UI

今回の「セルにボタン／プルダウンを追加する」は、**セルツールバーにボタンを追加し、そこから選択メニューを開く**ことを指す。HTMLフォーム内に選択欄を常設する意味ではない。

Zizai拡張から標準の拡張APIで追加する方針とし、VS Code本体・Jupyter拡張の上書きや改造を前提にしない。具体的なメニュー構成・APIと、VS Code／Kiroでの表示・操作は未検証。

## 既存調査との関係

[TASK-001-01の先行調査](../research/notebook-ui/TASK-001-01.md) は、HTMLフォームをセル内に常設する場合の制約と試作を扱った。そこにある標準APIでのフォーム配置の制約を、セルツールバーへのボタン・メニュー追加が不可能という意味に広げない。

今回の合意は呼称と選択UIの対象の整理であり、詳細HTMLフォームの要否・配置を新たに確定するものではない。先行試作や両IDEの実機確認を合格・完了に変更しない。今回の変更は文書のみ。
