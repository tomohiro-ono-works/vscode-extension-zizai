# ZizAI

VS CodeのNotebook入力支援と、VS Codeに依存しないPythonコネクタ／アクションを検討するプロジェクトです。

## 設計の作り直し（2026-11-08）

利用者の依頼により、旧要件・設計・フォーム／サイドバーの試験資料を削除し、新方式に関係する調査を残しています。新しい要件定義書はまだ作成していません。

検討対象は、`@ziz`による入力開始、セル内の選択支援、階層的な`%%`マジック、JSON／YAMLによる定義です。正確な操作方法・生成方式は未確定で、既存試作の成功をこの方式の実証とは扱いません。スニペットの作成・登録は利用者が担当します。
